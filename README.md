## About

Personal portfolio website showcasing projects, skills and experience. Built with React and Vite, styled with SCSS and animated with Framer Motion. Supports multiple languages via i18next and includes a contact form that sends messages directly through the Telegram Bot API.

## Pages

| Page | Description |
|---|---|
| **Home** | Hero section, skills and projects overview |
| **About** | Personal info and experience |
| **Contacts** | Contact form with Telegram Bot API integration |

## Features

- **Multi-language support** — i18next with browser language detection
- **Telegram contact form** — messages sent directly via Telegram Bot API
- **Smooth animations** — page and element transitions with Framer Motion
- **Responsive** — adaptive layout for all screen sizes
- **Code quality** — ESLint, Stylelint and Prettier

## Tech Stack

| Technology | Purpose |
|---|---|
| React 18 | UI framework |
| Vite | Build tool |
| SCSS / Sass | Styling |
| Framer Motion | Animations |
| Mantine UI | Component library |
| React Router | Navigation |
| i18next | Internationalization |
| iMask | Input masking |
| Swiper | Slider component |
| ESLint / Prettier / Stylelint | Code quality |

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Vergos1/portfolio-v1.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
